# Rat Trainer

Rat Game 的独立 Windows EXE 修改器。目标版本为 Steam **Build 26403247**、Unity **6000.2.6f1**、Windows x64 / Mono。

当前提供 **v1.3.4 两个独立 EXE**，各自内置游戏连接组件与角色图片，无需同目录 DLL、Python 或额外下载。使用 Windows 的 .NET Framework 4.5 及以上运行环境。

| 文件 | 用途 |
| --- | --- |
| **`dist\RatTrainer-Host-v1.3.4.exe`** | 房主沙盒版：AI 厨师、任务规则、辅助功能安装、设置与连接、关于五页。沙盒控制仅限房主；独立辅助插件在本机使用。 |
| **`dist\RatTrainer-All-v1.3.4.exe`** | 全能版：保留原有功能，增加辅助功能安装和关于，共八页。包含可用于非房主的本机功能。 |

v1.3.4 修复队友标点同步：补全 Steam 好友邀请路径下的大厅成员加入，使用同步时间、玩家网络对象和同步关卡进行匹配，并在连接就绪后补发标点。收发双方必须更新地图标点插件。

v1.3.3 在两个版本的辅助插件卡片上增加可直接点击的“卸载此插件”。未安装时显示灰色，安装或卸载过程中暂时禁用；操作完成后立即刷新状态。无需再右键寻找卸载菜单。

v1.3 修复了首次打开时顶部控件重叠和按钮悬停后的黑白边角。布局改用容器管理，按钮与开关采用单一绘制流程。开关左侧明确设为“关”，右侧明确设为“开”，重复点击同侧不会反向切换。

两版采用统一的中文“关 / 开”控件与“减号 / 数值 / 加号”输入框，加入游戏原始的 RoboChef 机械厨师头像、老鼠近照和角色场景图。房主版为厨房橘，全能版为奶酪金。素材来源见 [美术来源](../desktop/assets/SOURCES.md)。

两个版本各自保存桌面偏好。同一时间只运行一个版本，切换时先关闭另一个窗口。请使用 Releases 中标注为最新版的文件。

房主版已移除无限弹药、物品生成、房主角色和客机协同按钮。客机协同在房主版始终关闭；后台也会清除旧版保存的这些开关。全能版保留原有功能，游戏内备用面板默认关闭。

独立的是桌面控制程序；实际修改仍由安装在游戏目录的连接组件执行。EXE 首次运行可以自行安装该组件，不需要另开安装脚本。

## 无系统标题栏与关于

v1.3.2 修复了切换到其他窗口再切回来时出现的最外圈白边。保留拖动、缩放和窗口按钮，同时阻止系统在激活切换时重新绘制外框。两个版本已通过真实不透明离线窗口的切出 / 切回检查，房主版另检查了实际最小化后还原。游戏检测仍保持暂停。

v1.3.1 使用无系统标题栏的整体窗口。最小化、最大化 / 还原和关闭按钮与页面顶部融为一体，拖动顶部空白区或左上名称可以移动窗口，双击可最大化 / 还原，窗口边缘可调整大小。最大化避开任务栏，还原保留原窗口尺寸。

两个版本的侧栏末尾均有“关于”，作者栏只显示 **MaOnStEr969**，不添加简介或联系方式。

v1.3.4 更新地图标点插件与共享 Core 至 1.0.1；收发双方需要退出游戏，使用新版 EXE 更新地图标点插件并重新进入房间。仅替换 EXE 不会更新游戏内插件；新旧标点协议不互通。Trainer 游戏连接组件仍为 v1.3.0，无需为本次修复重装该组件。

## 使用

游戏目录会自动从 Steam 安装位置和游戏库中查找；手动选择后会记住该位置。

1. 关闭游戏。
2. 双击 **`RatTrainer-Host-v1.3.4.exe`** 或 **`RatTrainer-All-v1.3.4.exe`**，在“设置与连接”中确认游戏目录。
3. 点击 **“安装 / 更新组件”**。之前安装过 1.0、1.1 或 1.2 版，也需要更新一次。两版共用同一套 1.3.0 游戏组件。
4. 点击“启动游戏”或正常从 Steam 启动。等待桌面窗口显示“已连接”。
5. 打开总开关，再开启所需功能、调整数值。等待窗口显示游戏确认结果。

离线时可以先调整设置；连接后到“设置与连接”点击“将暂存设置应用到游戏”。总开关关闭时，已选择的角色与沙盒开关不会生效。

房主沙盒版需先创建房间，成为房主后才允许应用设置。离开房主状态后，连接组件会关闭由房主版启用的修改。该限制同时存在于桌面程序和游戏组件；房主版不提供游戏内备用面板。

关闭 EXE 会发送“全部关闭”；异常退出或停止心跳约 10 秒后，游戏组件自动关闭由 EXE 启用的修改。已生成物品、已完成任务、已写入的外观存档不会自动撤销。窗口置顶、日志和卸载入口位于“设置与连接”。

| 快捷键 | 操作 |
| --- | --- |
| F6 | 打开 / 关闭备用面板，需先在 EXE 设置页启用；原有 F8 / Insert 配置也保留 |
| Esc | 关闭面板 |
| F7 | 全能版记录当前位置 |
| F9 | 全能版返回记录位置 |
| F10 | 关闭 Trainer 修改；独立辅助插件继续运行 |

备用面板打开时会释放鼠标并屏蔽角色移动、视角及交互输入。使用桌面窗口时可以按 Alt+Tab 切换，游戏组件会保持后台运行。

## 单独的辅助插件安装 EXE

`dist\RatAssist-Installer-v1.0.1.exe` 是单独的安装器，仅提供地图标点和阵营实时地图的安装、更新、分别卸载。它内置所需加载器、两个辅助插件与共享 Core，不包含 `RatTrainer.dll`，无需携带旁边的 DLL 或脚本。

使用方法：关闭游戏和已打开的 Trainer → 打开安装器 → 确认游戏目录（也可选择 `Rat Game.exe`）→ 分别点击两个安装按钮。安装完成后关闭安装器，正常启动游戏即可。卡片中的“卸载此插件”可以分别移除功能。已通过 Trainer 安装的辅助插件可以识别和更新，卸载时会保留其他仍在使用的组件。

作者名为 **MaOnStEr969**。游戏版本要求及阵营规则与下方说明一致：标点共享需要小鼠队友也安装标点插件；实时位置只需本机安装。辅助插件安装后不依赖 Trainer 的总开关，也不需要安装器常驻。

构建：`powershell -NoProfile -ExecutionPolicy Bypass -File .\build-assist-installer.ps1`。加入 `-ReusePlugins` 复用已有辅助 DLL；加入 `-Test` 执行离线界面和隔离目录安装检查。安装器源码在 `assist-installer/`，验证记录在 `test-output\assist-installer\`。本次未向真实游戏目录安装或恢复游戏运行检测。

## 独立辅助插件：两个安装按钮

两版左侧都有“辅助功能安装”。先关闭游戏、在“设置与连接”确认游戏目录，再点击需要的按钮：

| 按钮 | 安装后效果 |
| --- | --- |
| 安装地图标点插件 | 默认按 **G** 在准心射线命中的实体表面创建标记；**Shift + G** 清除自己的标记。可透过障碍显示，每人默认最多 3 个、保留 30 秒。 |
| 安装阵营位置插件 | 按原游戏 **Tab** 地图键，实时叠加小鼠头像与玩家名称；使用 X/Z 水平位置，不显示高度。厨师也可按 Tab 查看自己的地图。 |

安装完成后下次启动游戏自动加载。只用这两个功能时，不必点击顶部“安装 / 更新组件”，也不必开启 Trainer、总开关或房主协同；无需桌面 EXE 保持运行。

小鼠只能看到小鼠阵营的标点和位置；厨师只看到自己的标点和位置。原游戏的幽灵角色归入小鼠阵营。换角色、换地图、离开对局会清理旧标点；已废弃的角色躯体与 AI 占位角色不会作为玩家显示。

- **共享标点**使用 Steam 房间成员数据，不需要房主安装 Trainer。创建和查看标点的小鼠队友都需安装标点插件；未安装的游戏不会绘制自定义标记。非 Steam / LAN 房间暂只显示自己的标点。
- **玩家位置**只需本机安装位置插件，从本机收到的角色同步数据绘制；不要求队友安装。仅在按住原地图键时显示。
- 标点附着在可同步的活动实体上时会随其移动；未命中实体表面时不创建标点。视野外的世界标点不显示边缘箭头，可在地图中查看。
- Trainer 总开关、F10 和关闭 EXE 不会关闭这两个独立插件。
- 卸载：关闭游戏，在“辅助功能安装”页点击对应卡片中的“卸载此插件”。分别卸载只移除选中的插件，保留另一项辅助插件及 Trainer。卸载 Trainer 连接组件也会保留辅助插件。共享文件仅在不再被其他已安装组件使用时清理，配置和备份会保留。

插件位于 `BepInEx\plugins\RatAssist\`：共享的 `RatAssist.Core.dll`、标点 `RatAssist.Markers.dll`、位置 `RatAssist.TeamMap.dll`。不要单独移走仍被另一个插件使用的 Core。

首次加载后可在 `BepInEx\config\local.ratgame.mapmarkers.cfg` 修改标点键、持续时间和数量；退出游戏修改后重新启动生效。加载日志见 `BepInEx\LogOutput.log`。

## 全能版功能与非房主支持

| 页面 / 功能 | 只在自己电脑安装，非房主 | 房主也安装并开启协同 |
| --- | --- | --- |
| 无限冲刺、饱食保持、生命保护 | 支持 | 支持 |
| 免疫中毒、眩晕、跌落惩罚 | 支持 | 支持 |
| 老鼠移速、跳跃、交互范围 | 支持 | 支持 |
| 记录位置、传送返回 | 支持 | 支持 |
| 厨师移速、抓取范围 | 支持 | 支持 |
| 帽子选择、游戏内帽子解锁、肤色 | 支持 | 支持 |
| 存档备份、恢复 | 支持 | 支持 |
| 无限弹药 | 需要房主支持 | 支持 |
| 自己的长按交互加速 | 需要房主支持 | 支持 |
| 任务所需次数 / 时间比例 | 需要房主支持 | 支持 |
| AI 移速、听觉、视觉距离、识别概率、暂停 | 需要房主支持 | 支持 |
| 食物、杂物、子弹、枪的生成 | 需要房主支持 | 支持 |

**没有“任意未修改房间里，客机控制一切”的保证。** AI、物品生成和实际弹药由房主程序执行。只改客机上的显示值不能实现这些效果。本工具提供显式的房主协同通道；未取得支持时相关开关会禁用并显示原因。

房主协同用法（房主需使用全能版）：双方安装同一版本，进入房间后，由房主在“设置与连接”中打开“允许客机协同”。客机会自动检测。客机的弹药与交互只作用于该客机角色；AI 和任务规则是全局效果。全局设置由房主优先控制，否则首个申请的客机取得控制，直到关闭或断开。

协同请求会定期续期；客机断线或超过 6 秒未续期后，房主恢复参数。全局沙盒开关和客机授权每次启动都保持关闭，避免重启后意外沿用整局修改。

## 参数与恢复

- 老鼠移动：0.5–5 倍；跳跃：0.5–4 倍；交互范围：1–5 倍。
- 厨师移动：0.5–4 倍；抓取范围：1–5 倍。
- 长按交互：1–10 倍；任务工作量：原来的 0.1–3 倍。
- AI 移速：0.1–3 倍；听觉：0–3 倍；视觉距离：0–100 米；识别概率：0–1。
- 每次生成 1–10 个物品，同局修改器生成且仍存活的物品最多 50 个。
- 关闭开关后恢复移动、跳跃、范围、AI 和弹药的原值。不会反向撤销已完成任务、已生成物品或已保存外观。
- 生命保护作用于活着的老鼠，不解除被抓，也不复活已生成的幽灵。
- 位置书签只适用于当前地图和当前角色。被抓、藏入物品或死亡时不能传送。
- 任务比例覆盖厕所、推瓶、放水、啤酒、铃铛、蜡烛、警报和燃气任务。电脑谜题数量保留生成时的值，以免已生成题目与计数不一致。
- 外观工具覆盖游戏内帽子；单独商品绑定的专属帽子仍使用游戏原来的判断。

## 存档、配置和卸载

原游戏存档：`%USERPROFILE%\AppData\LocalLow\sokpop\Rat Game\main.sav`。

桌面窗口偏好与暂存设置：`%LOCALAPPDATA%\RatTrainer\desktop-all.json` 与 `desktop-host.json`。全能版首次使用可读取旧 `desktop.json`，之后分别保存。

修改器数据位于游戏目录下：

- `BepInEx\config\RatTrainer\options.json`：面板配置。
- `BepInEx\config\RatTrainer\backups\`：外观存档备份。解锁或保存外观前自动备份，恢复前也先备份当前状态。
- `BepInEx\config\RatTrainer\diagnostics.json`：运行诊断，包含补丁加载情况和当前角色数值。
- `BepInEx\config\RatTrainer\desktop\`：桌面程序与游戏的本地通信文件。请求绑定当前游戏会话，过期请求不会执行。
- `BepInEx\LogOutput.log`：加载与错误日志。

卸载时关闭游戏，在 EXE 的“设置与连接”中点击“卸载游戏连接组件”。卸载会保留配置与存档备份；发现其他插件时保留共享加载器。已被其他程序修改过的安装文件会保留并提示，不会盲目删除。旧版脚本仅用于原有单组件记录；v1.3 的共享组件请用 EXE 管理，脚本会拒绝修改新版记录。

安装器校验游戏程序集版本和包内文件哈希，不覆盖 `Assembly-CSharp.dll`，也不覆盖不兼容的其他加载器。游戏更新后若版本校验失败，需要重新分析并构建。

## 构建与测试

v1.3.3 的离线界面与隔离目录安装卸载检查位于 `test-output\v1.3.3\`，覆盖逐项卸载辅助插件后保留另一项插件、Trainer 与共享加载器。本次仅更新桌面 EXE，游戏组件与辅助插件保持原版本。

两个 EXE、Trainer 组件和两个辅助插件均已完成编译。离线回归覆盖正常窗口首次显示（不先改边框触发重排）、最小窗口与放大还原、100%/125%/150% 布局比例、页面切换、按钮悬停/按下/离开/禁用、开关鼠标与键盘交互、阵营规则与房主功能限制。另在临时模拟目录验证独立安装、重复更新、逐个卸载、旧记录迁移、被修改文件和其他插件的保留。历史构建、重复截图和临时测试副本已清理；测试代码保留，可重新生成检查结果。`tests\ChromePreview.cs` 加载实际发布 EXE 的离线模式，供 computer-use 查看完整不透明窗口；不会启动游戏或读取游戏状态。注意：透明预览和打印截图不能替代实际窗口焦点切换验证。比例检查不等同于真实系统 DPI 切换测试。离线渲染不读取游戏状态、不写桌面偏好、不发送指令、不安装组件、不启动游戏。按照“暂停检测”的要求，游戏连接与联机运行测试继续暂停；界面检查不代表游戏功能已完成新一轮验证。

本机不需要安装新的 .NET SDK。构建使用 Windows 自带的 .NET Framework C# 编译器，并引用本机游戏 DLL。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\bootstrap.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\build-desktop.ps1
```

`build-desktop.ps1 -GamePath <目录>` 可指定游戏目录。构建会先生成游戏组件，再将加载器、组件与角色图片分别嵌入两个 EXE。房主版通过 `HOST_SANDBOX` 构建配置生成。构建不会自动安装或启动游戏。

设计用离线渲染命令为 `RatTrainer-All-v1.3.4.exe --render <输出目录>` 与 `RatTrainer-Host-v1.3.4.exe --render <输出目录>`。预览包含开关开启和关闭的暂存状态，并明确标注未连接游戏；正常启动不使用这些演示设置。

仅重新构建桌面界面可使用 `build-desktop.ps1 -DesktopOnly`，复用已有内嵌组件包。

新增离线回归命令：`powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\desktop-regression.ps1`。安装操作限定在临时模拟目录，跳过真实游戏进程检测。传入 `-UiOnly` 仅检查界面和窗口，不执行安装器测试。

已有核心测试位于 `tests\run.ps1`；`tests\QaPlugin.cs` 是单独的本机联机测试驱动，均未包含在 EXE 中。检测恢复后可另行执行。游戏安装目录需使用英文路径，以规避已观察到的 Unity / Mono 编码问题；EXE 本身可以放在中文路径下。

游戏组件源码位于 `src/`，独立辅助源码位于 `assist/`，桌面程序源码位于 `desktop/`。游戏反编译分析文件不参与构建，已清理；仓库不包含游戏程序集或完整游戏资源。
