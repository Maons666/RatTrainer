## 标点同步修复

- 适配 Steam 好友邀请直接连接游戏、但尚未加入 Steam 大厅成员列表的情况；补全标点共享所需的大厅成员身份。
- 加入大厅时拦截本次补全操作产生的重复游戏连接回调，保留已经建立的游戏连接。
- 使用游戏同步时间判断标点有效期，避免两台电脑系统时间不同导致队友标点被当作过期。
- 使用 Steam 成员编号、当前玩家网络对象和同步关卡进行匹配，不再依赖显示名或本地活动场景名。
- 等待共享连接期间保留本机标点，连接就绪后补发；临时发送失败后重试。
- 保持阵营规则：小鼠仅显示同阵营标点，厨师的标点不上传、仅自己可见。

## 升级方式

**发送和接收标点的玩家都需要更新地图标点插件。仅换一个新版 EXE 不会更新游戏内插件。**

1. 所有人先退出游戏。
2. 打开新版 Trainer 的“辅助功能安装”，或新版独立辅助安装器。
3. 确认游戏目录，点击“更新地图标点插件”（未安装时显示“安装”）。
4. 双方重新启动游戏并进入同一房间，再用 **G** 标点。

本次同步协议升级，旧版与新版标点插件不互通。共享标点仍需要队友安装插件；小地图实时位置只需本机安装。没有 Steam 大厅的局域网 / 直连环境仍仅显示本机标点。
