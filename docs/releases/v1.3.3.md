# Rat Trainer v1.3.3 · 三应用发布

作者：**MaOnStEr969**

本次提供三个独立 Windows x64 EXE：

| 文件 | 用途 |
| --- | --- |
| `RatTrainer-Host-v1.3.3.exe` | 房主沙盒版：AI 厨师、任务规则和辅助插件管理。 |
| `RatTrainer-All-v1.3.3.exe` | 全能版：保留完整功能与辅助插件管理。 |
| `RatAssist-Installer-v1.0.exe` | 单独安装、更新和卸载地图标点与阵营实时地图。 |

## 本次更新

- 两个 Trainer 的辅助功能卡片新增直接可见的“卸载此插件”。
- 卸载单项插件保留另一项辅助插件和 Trainer；不再需要通过右键菜单寻找入口。
- 独立辅助安装器内置所需加载器和两个辅助插件，不需要安装 Trainer 后端。
- 保留无系统标题栏、切换窗口白边修复和作者信息。

## 使用

关闭游戏和其他 Trainer / 安装器，打开所需 EXE，确认自动识别的游戏目录。只用辅助功能时分别点击两个安装按钮，安装完成后可关闭桌面程序，再正常启动游戏。卸载前同样需要关闭游戏。

适配 **Steam Build 26403247 / Unity 6000.2.6f1 / Windows x64 Mono**，需要 .NET Framework 4.5 或更新版本。已安装 v1.3.0 游戏组件的用户无需为了桌面更新重新安装组件。Steam 阵营标点共享需要队友也安装标点插件；阵营位置显示只需本机安装。

离线验证：全能版 1520 项、房主版 1228 项、独立安装器 365 项检查通过。当前版本没有恢复游戏内或联机运行测试。

附带 `SHA256SUMS.txt`，可用于核对三个 EXE 的下载完整性。加载器及美术来源见仓库 README。

另附 `THIRD-PARTY-NOTICES.txt`，包含加载器依赖的许可证全文及源码链接。
