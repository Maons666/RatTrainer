# Rat Trainer v1.3.5 · 标点联机测试版

作者：**MaOnStEr969**

**这是预发布测试版，尚未完成真实双机联机验证。** 用户实测 v1.3.4 仍看不到队友标点。本机日志确认插件 1.0.1 已加载，并显示“同步已就绪”，但旧版没有记录收包和过滤原因，因此不能据此认定队友已收到，也不能确定所有失败都源于同一个原因。

| 文件 | 用途 |
| --- | --- |
| `RatTrainer-Host-v1.3.5.exe` | 房主沙盒版，内置新版标点插件。 |
| `RatTrainer-All-v1.3.5.exe` | 全能版，内置新版标点插件。 |
| `RatAssist-Installer-v1.0.2.exe` | 独立辅助安装器；只修复辅助插件时下载这个即可。 |

## 本次改动

- 增加游戏既有联机连接上的可靠消息通道，由房主验证发送者身份并转发给小鼠队友，不依赖 Steam 大厅成员数据传递。
- 房主为厨师时仍可转发，但不接收用于绘制的小鼠标点；厨师自己创建的标点留在本机。
- 使用可靠分片传输多个标点，并定期补发仍有效的状态，让新加入的队友和暂时错过状态的客户端恢复同步。
- 增加接收方回执。发送调用完成不再提示队友收到；收到实际接收方插件回执后显示“队友已收到”。
- 匹配游戏当前控制角色，移除 Steam 备用接收中额外的对象所有权限制。保留角色、阵营、关卡、有效期与数据范围检查。
- 保留 Steam 元数据通道作为备用，同一标点只绘制一次。
- 新增 Ctrl+G 同步状态和周期日志，区分未建立通道、未收到数据、数据被过滤和已有接收确认。

## 更新与验证步骤

1. **房主和参与标点的队友都退出游戏。** 即使房主玩厨师，也需更新标点插件以使用新转发通道。
2. 打开三个新版 EXE 中任意一个，在辅助安装界面点击“更新地图标点插件”。仅替换 EXE 不会更新游戏内插件。
3. 房主可只使用独立辅助安装器；无需安装 Trainer、开启总开关或客机协同。标点插件应为 **1.0.2**。
4. 双方重启游戏并进房，在同一位置测试 **G** 标点；先显示等待确认，队友接收后显示“队友已收到”。
5. 若仍不可见，双方按 **Ctrl+G**。游戏目录 `BepInEx/LogOutput.log` 中的 `[标点诊断 1.0.2]` 会记录连接、接收、确认、可见标点数量及过滤原因，便于继续精确排查。

未更新的房主不能提供新游戏通道；旧 Steam 备用路径仍可能可用，但不会产生新通道的接收回执。旧标点插件 1.0.0 不支持当前 Steam 备用协议。

## 验证范围

- 已针对 Build 26403247 / Unity 6000.2.6f1 的实际程序集编译。
- 38 项 Steam 备用通道检查、32 项游戏消息通道模拟检查。
- 两个 Trainer 和独立安装器执行离线界面及隔离目录安装卸载检查。
- **没有启动或附加游戏，没有自动安装到真实游戏目录，也没有完成真实双机联机测试。** 预发布标记在实测确认前保留。

随包提供 `SHA256SUMS.txt` 与 `THIRD-PARTY-NOTICES.txt`。小地图插件版本仍为 1.0.0，Trainer 连接组件仍为 1.3.0。
