# 两个桌面版本的界面调整

产品：本地 Rat Game 修改器，提供中文控制面板。
性格：俏皮、清楚、克制。
世界：厨房里的奶酪色、机械厨师海报和躲在角落的小老鼠。
视觉重点：页面标题右侧的原始角色美术；房主版以 RoboChef 为主，全能版以老鼠为主。
统一细节：每个开关都直接显示“关 / 开”，数值采用相同的减号、输入框和加号。

原界面问题：开关没有文字状态，圆点与底轨比例不稳定；控件与原生数值框风格不一致；页面全部使用相同的大暗色矩形；标题、说明、范围提示的水平位置缺乏统一；没有游戏角色形象；所有房间功能挤在一个页面。

改动：4px 间距体系、低饱和中性色、奶酪金/厨房橘两种版本识别色、清楚的按钮状态、统一开关和数值框、真实游戏角色图、房主版独立导航及房主身份限制。

使用 unslop 工作流，来源：[Damir Sokolovsky](https://x.com/heydamir)，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。本文未复制技能正文。

界面检查使用离线渲染入口，不读取游戏状态、不发送操作、不启动游戏。游戏运行检测继续暂停。


v1.3 回归修复：顶部、侧栏页脚和目录选择改为布局容器，避免首次显示依赖 Resize 事件。按钮和开关改为纯自绘 Control，每次重绘先清理四角，避免原生 Button / CheckBox 的主题边框残留。辅助安装采用两张对齐的说明卡，提供两个安装按钮。回归保留正常窗口边框，不再通过改变 FormBorderStyle 意外修正待测布局。


v1.3.1：移除原生标题栏，使用顶部同色的线形窗口按钮。保留系统移动、边缘缩放、最大化工作区与关闭事件；显式校正无边框客户区和还原尺寸。关于页与现有角色图和卡片保持一致，作者栏只显示用户提供的 MaOnStEr969。


v1.3.2：修正失活 / 重新激活时系统按 WS_THICKFRAME 重画外框的问题。保留原生缩放样式，关闭当前窗口的 DWM 非客户区绘制；WM_NCPAINT 不再绘制外框，WM_NCACTIVATE 按官方约定传入 lParam=-1，正常更新激活状态并跳过边框重绘。窗口句柄重建、主题和合成状态变化时重新应用策略。验证增加实际不透明发布窗口的跨应用切换，不能仅依赖透明窗或 DrawToBitmap / PrintWindow。

参考：[WM_NCACTIVATE](https://learn.microsoft.com/en-us/windows/win32/winmsg/wm-ncactivate)、[DWM 非客户区绘制策略](https://learn.microsoft.com/en-us/windows/win32/dwm/composition-ovw)。

v1.3.3：在辅助插件卡片的安装按钮和状态下方提供始终可见的“卸载此插件”链接；未安装或操作中禁用。沿用独立辅助安装器的灰色禁用链接样式，禁用链接本身以避免系统禁用控件颜色覆盖。卡片保留原高度，安装、状态、卸载与底部提示各占一行。
